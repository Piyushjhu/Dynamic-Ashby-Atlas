Data review
and plotting workflow

The website and scientific figures use the same reviewed literature files. These steps cover source registration, extraction, pairing, estimates and publication.

01

Discover & register

Register the publication

Find primary experimental papers, remove duplicate references by DOI and review the original publication before extracting values. Search results and abstracts remain review leads.

Register the publication, authors, year, DOI, material classes and a stable link in sources.json. Papers awaiting extraction remain visible in the source library with their review status.

02

Extract & preserve

Extract reported values

Read the primary publisher or author full text, including methods, units and footnotes. Record the exact material and state, reported values, uncertainty definitions, table cells and pages. Static values stated literally in the results text may also be admitted, using paragraph and page locators, a checked extraction image and a distinct prose-review status. Record the source-file fingerprint to identify the reviewed version.

Dynamic evidence enters literature_values.json; reviewed static and ambient properties enter the common property input. Distinguish the authors’ experiments from cited comparisons, supplier inputs and simulations. Results reduced from measured wave histories remain experimental, with the reduction method recorded.

03

Audit & admit

Review evidence and pairing

A verified HEL–spall pair requires both values for the same identified shot and visual source-table verification. Review of machine-readable tables (XML) remains a separate level from visual table checks. Independent values, ranges and cross-paper combinations retain their own evidence categories.

Reviewed exclusions remain in the ledger. The current compilation contains — verified same-shot pairs.

04

Review missing coordinates

Record matches and estimates

Explicit rules may match a missing coordinate to a reported value for the same material, or to a documented material-state or composition proxy. A conditional yield-strength conversion can estimate HEL when configured.

Link each inferred coordinate to its donor or model inputs. Yield strength cannot supply missing spall strength; unsupported cases remain unresolved.

05

Group & plot

Construct material clouds

Group supported records by exact material name. An ellipse in log space encloses the independent HEL and spall bounds. Colour identifies material class; darker fill indicates more supporting extracted records.

A documented minimum display width keeps single values and narrow ranges visible. The ellipse describes supported property bounds, not uncertainty or a fitted joint distribution.

06

Compare & explore

Compare static and dynamic properties

The property input contains reviewed static, ambient, thermal and fracture measurements, each linked to its source, extraction location, method and material condition. Yield strength, tensile strength, K-based toughness and J-integral results retain their definitions and units. Conditional KQ and an elastic K component used within a J calculation are identified as such.

Static and dynamic maps use independent literature sets. Material clouds may span test conditions, and class coverage may span alloys. Static condition points use reviewed links, including links between separate tensile and fracture test populations. The single-property strips retain materials missing one coordinate. Embeddings use complete observations and state their input features, scaling and available source and stability checks.

A separate static reference layer uses material-family ranges from Ashby’s 2021 Tables A3–A4 ↗, with visually checked cells and source locators. Metal yield, polymer nonlinearity and brittle tensile fracture strength retain their own definitions. George, Raabe & Ritchie (2019), Figure 2d ↗ provides chart context and links to earlier sources; its outlines do not add experimental points.

Select Reviewed measurements under Static dataset to see the experimental input alone. Reference bounds are excluded from measured-value counts, HEL estimates, rankings and embeddings. Download reference ranges and locators ↓

07

Build & publish

Build and check the website

The builder reads the literature records, reviewed property input and published reference ranges. It checks the records, applies configured completion rules and regenerates plotted data, source links, coverage counts and downloads together.

A repository update triggers a fresh build in GitHub Actions. The public build uses literature inputs and approved connected-source data; private study overrides are excluded.
