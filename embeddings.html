Interpreting the plot

How to assess
a pattern

01

Check which properties are inputs.

When HEL or spall is an input, colour patterns based on that property can follow directly from how the plot was constructed. They do not establish which other properties explain the shock response.

02

Check whether groups follow papers.

Observations from one paper can share material, apparatus and analysis choices. A group of nearby points may therefore reflect a particular study. Compare the fraction of neighbours from the same paper with its random baseline, and check how many papers contribute.

03

Check which observations are included.

Each analysis uses observations with all its required input values. This subset can be small or unrepresentative of the full dataset. Missing static properties are not filled with class averages; an unavailable analysis states why it could not be computed.

What these methods support

UMAP emphasises similarity among nearby observations. Diffusion maps describe connections through sequences of similar observations. Neither method shows that an input causes a change in HEL or spall strength. Axis direction, group area and gaps between distant groups have no direct physical meaning.

The layout can change with the input properties, their scaling, the number of neighbours and, where applicable, the random seed. Download the analysis JSON to inspect the inputs, included observations, method settings and available stability checks.
