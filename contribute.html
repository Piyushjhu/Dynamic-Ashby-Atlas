The collection
How the data are stored

Discovery lists the available datasets without publishing numerical values. Start here if you have not reviewed the source schema. Collections containing XLSX files or spall values without HEL can remain in discovery while their schema and measurement basis are reviewed.

Map experimentally measured values.

HEL must be the elastic-limit measurement, not peak shock stress. A spall-only dataset cannot supply a missing HEL. Leave an unavailable property mapping blank; it remains unresolved. Model predictions, simulations and yield-derived coordinates do not enter this layer. Experimentally reduced strengths retain their reported basis.

The basis field must contain experimental, experimental_measurement, direct_measurement or experimental_reduction. Missing or unsupported values stay held for review.

Credentials stay with you

Use an encrypted secret.

The browser never asks for an API token or sends requests to your collection. Scheduled synchronization runs in your research repository.

Create an Actions secret named ASHBY_DATA_SOURCE_CREDENTIALS. Its value is a JSON object mapping your connection ID to its API key or token:

{"my-lab-shock-data": "YOUR_API_KEY"}

Keep this value out of configuration files and commits. Public sources can use “no credential”.

Reviewed literature

Add a paper.

Publication evidence follows the existing review workflow. These files describe literature independently of connected experimental sources.

sources.json

The publication registry: citation, title, year, DOI, link, material classes and extraction status.

literature_values.json

The evidence ledger: exact material and state, reported properties, units, conditions and extraction locators.

literature_clouds_config.json

Material classes, distinct class colours and cloud rendering settings.

Optional donor matches and yield-to-HEL inputs belong in exploratory_ashby_config.json. Inferred coordinates remain separate from reported measurements.

Before evidence becomes a cloud

  1. Verify values in the original paper.
  2. Record exact material and specimen state.
  3. Preserve units and uncertainty definitions.
  4. Confirm whether properties belong to the same shot.
  5. Attach a publication link and extraction locator.
  6. Leave unsupported counterparts missing.
