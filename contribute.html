The collection
How the data are stored

Discovery mode lists datasets without publishing numerical values. Use it while reviewing file formats, column definitions or experimental basis, including collections with XLSX files or spall-only data.

Identify the measured property columns.

Map HEL to the measured elastic limit and spall to the reported tensile-failure stress. Peak shock stress is a different property. Leave a missing property mapping blank. This layer accepts experimental measurements and reductions, with their stated basis; model predictions and yield-derived estimates are excluded.

The basis field must contain experimental, experimental_measurement, direct_measurement or experimental_reduction. Missing or unsupported values stay held for review.

Repository credentials

Store credentials in Actions secrets

Collection access runs in your repository’s scheduled workflow. This form creates configuration files and setup links; it does not request a collection token or contact the collection.

Create an Actions secret named ASHBY_DATA_SOURCE_CREDENTIALS. Its value is a JSON object mapping your connection ID to its API key or token:

{"my-lab-shock-data": "YOUR_API_KEY"}

Keep this value out of configuration files and commits. Public sources can use “no credential”.

Reviewed literature

Add a paper.

Review the primary publisher or author full text before adding literature values. Preserve the authors’ measurements, material conditions, units and extraction locations. Static results stated literally in the primary text use a separate prose-review status with paragraph, page and checked-image evidence.

sources.json

The publication registry: citation, title, year, DOI, link, material classes and extraction status.

literature_values.json

Dynamic evidence: exact material and state, reported HEL or spall, units, test conditions and extraction locators. Stage new static properties in data/static_literature/primary_measurements.json, then merge them into ZAKI/ZAKI.csv.

literature_clouds_config.json

Material classes, distinct class colours and cloud rendering settings.

Optional donor matches and yield-to-HEL inputs belong in exploratory_ashby_config.json. Inferred coordinates remain separate from reported measurements.

Extraction checklist

  1. Verify values and experimental methods in the primary full text.
  2. Record exact material and specimen state.
  3. Preserve units and uncertainty definitions.
  4. Confirm whether properties belong to the same shot.
  5. Attach a publication link and a table-cell or literal-prose locator.
  6. Leave unsupported counterparts missing.
